# Concha de Palacio — Casa Creativa

Site institutionnel statique bilingue du groupe Concha de Palacio, basé à San Diego, California.

## Prévisualisation locale

Depuis ce dossier :

```bash
python3 -m http.server 4173
```

Puis ouvrir `http://localhost:4173` pour la version anglaise ou `http://localhost:4173/es/` pour la version espagnole.

Les URL des trois univers sont centralisées dans `config.js`.
